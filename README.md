# Edge AI Plastic Waste Detector

## Project Overview

This project aims to develop a smart environmental monitoring system capable of detecting plastic waste in real time using computer vision and artificial intelligence.

The system will use a live camera feed to identify objects such as plastic bottles, bags, and other waste materials. When waste is detected, the system will trigger a small automated collection mechanism and store detection data such as time, location, and waste type in a cloud database.

The project combines:
- Artificial Intelligence
- Computer Vision
- Embedded Systems
- Real-Time Detection
- Cloud Data Logging

The main goal is to create a proof-of-concept system for automated plastic waste monitoring and collection.
